# HackUTD 2026: Event Info

Part of [HackUTD-2026](HackUTD-2026.md). Source: zeroday.hackutd.co, read 2026-11-07 7:15 AM.

## Basics
- **"Zero Day"**, presented by T-Mobile. ECSW building, UTD. Free. Teams of 1–4.
- Tracks: **up to 3 sponsor tracks + 1 HackUTD track** (Best Hardware / Best Design / Virality) + any MLH tracks; General is automatic (Devpost rules; the event site said 2). $60k+ prizes. Final demo video ≤ 2 min. Challenges are announced when hacking starts.
- The page doesn't list prizes or hardware-lab rules. The code of conduct is MLH's (assume no code written before 12:00 PM).
- Judging runs on HackUTD's open-source **Jury** platform (github.com/hackutd/jury).
