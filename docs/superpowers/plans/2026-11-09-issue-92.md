# Win agent: /hack-prep sponsor brief + prize targets Implementation Plan (issue #92)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/hack-prep <devpost url>` also writes `sponsor-brief.md` (each sponsor prize's tool, docs, access and past winners, all sourced) and `targets.md` (at most 2 ranked single-sponsor prizes, scored on team fit and integration depth). A rerun never overwrites a file the owner edited by hand.

**Architecture:** Two new bash helpers beside `page-text.sh`: `awards.sh` reads a Devpost gallery's winners list, and `save-output.sh` writes each output unless the owner edited the current one, in which case it writes `<name>.new.md` beside it. Two new committed templates. `SKILL.md` gains the brief and targets steps and routes all three outputs through `save-output.sh`.

**Tech Stack:** Markdown skill for Claude Code, bash, curl, python3 stdlib, `shasum` (all already installed; no new dependency).

**Spec:** `~/Developer/docs/superpowers/specs/2026-11-09-hackathon-win-agent-design.md` and issue #92 (`gh issue view 92`). Builds on #91's plan, `docs/superpowers/plans/2026-11-09-issue-91.md` on `main`. `/hack-kickoff` (the "real integration" bar) is a later ticket; `targets.md` does not write idea seeds.

### Task 2: `save-output.sh` keep-hand-edits writer

**Files:**
- Create: `hackathons/agent/skills/hack-prep/save-output.sh` (executable)

**Interfaces:**
- Produces: `save-output.sh <draft file> <dest file>`. Record file is `$(dirname dest)/.hack-prep.sha256` in `shasum -a 256` format (`<hash>  <basename>`), one line per output.
  - `dest` missing, or its current `shasum -a 256` equals the recorded hash for its basename: move the draft onto `dest`, replace that basename's line in the record with the new hash, print `wrote <dest>`.
  - Otherwise (hash differs, or no record line): move the draft to `<dest without .md>.new.md`, leave `dest` and the record untouched, print `kept <dest> (edited by hand); new version at <new path>`.
  - Exit 0 in both cases. Missing draft: exit 1 with a message.

- [ ] **Step 1: Write the tests as a script in the scratchpad, run, see them fail (file missing).**

```bash
W=$PWD/hackathons/agent/skills/hack-prep/save-output.sh
T=$(mktemp -d) && cd "$T"
echo v1 > d && $W d card.md && [ "$(cat card.md)" = v1 ] && [ ! -e d ] && echo "ok first write"
echo v2 > d && $W d card.md && [ "$(cat card.md)" = v2 ] && [ ! -e card.new.md ] && echo "ok untouched is replaced"
echo "my note" >> card.md
echo v3 > d && $W d card.md && grep -q "my note" card.md && [ "$(cat card.new.md)" = v3 ] && echo "ok edited is kept"
echo hand > other.md && echo v1 > d && $W d other.md && [ "$(cat other.md)" = hand ] && [ -e other.new.md ] && echo "ok no record is kept"
$W missing card.md; echo "exit $? (expect 1)"
grep -c card.md .hack-prep.sha256   # expect: 1 (one line per output, not appended twice)
```
